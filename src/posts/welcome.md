## A little taste of markdown

Everything on this site is written in plain markdown. That means **bold text**,
*italic text*, and ~~strikethrough~~ all just work. You can write `inline code`
like this, or drop in a full code block:

```js
function sayHello(name) {
  return `Hello, ${name}!`;
}

console.log(sayHello("world"));
```
